# Inventory Scanner V1 Feature List

1. Dashboard with total products, total units, low-stock count, attention count, low-stock list, and recent changes.
2. Barcode scanner using the iPhone browser camera when supported.
3. Manual barcode entry when camera scanning is unavailable.
4. Unknown barcode alert.
5. Quick new product setup from an unknown barcode.
6. Barcode-to-product linking.
7. Bottle/product name saved against a barcode.
8. Bottle size saved against a barcode.
9. Vendor saved against a barcode.
10. Editable bottle sizes and units such as ml, cl, L, oz, fl oz, pint, quart, and gallon.
11. Editable vendor names.
12. Automatic prefill after scan.
13. Missing information warning for bottle name, bottle size, and vendor.
14. Fill Now / Next choice for missing information.
15. Editable product information.
16. Current quantity.
17. Stock In.
18. Stock Out.
19. Set/overwrite quantity.
20. Quality/condition.
21. Editable quality/condition options.
22. Categories.
23. Storage locations.
24. Product search.
25. Inventory list.
26. Rapid scan mode.
27. Stock count mode.
28. Scan confirmation before saving stock.
29. Low stock level.
30. Low stock warning.
31. Out-of-stock identification.
32. Inventory history.
33. Previous vs new quantity history.
34. Date and time tracking.
35. Reason for adjustment.
36. Notes.
37. Vendor-based search/filter through inventory search.
38. Bottle-size search/filter through inventory search.
39. Duplicate barcode protection.
40. Google Sheet / Excel template column support.
41. Excel export.
42. Current inventory export.
43. History export.
44. Low stock export.
45. Products export.
46. Local SQLite database.
47. Automatic saving after each save action.
48. Data persistence after closing and restarting the app.
49. Database backup.
50. Restore backup.
51. iPhone web app/PWA support.
52. Same Wi-Fi access from iPhone to Mac.
53. Simple Mac launcher.
54. Demo/test mode.
55. GitHub-ready repo that excludes real inventory data.

Not included in this version:

- Admin mode.
- Light/dark mode.
